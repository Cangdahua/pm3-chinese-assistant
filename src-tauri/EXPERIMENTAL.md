# React/Tauri 原型：冻结，禁止发布

这个目录只保留为开发验证样本，不是 PM3 的发布客户端。正式产品主线是
`pm3-qml-client`。

安全边界：

- Tauri 打包已关闭；配置、窗口标题和界面均标记为“实验原型 / 禁止发布”。
- Rust 后端只放行明确列出的只读诊断命令。写卡、模拟、擦除、刷写、脚本执行和未知命令默认拒绝。
- 串口必须是 `/dev/cu.*` 下实际存在的字符设备。
- 仅允许 Homebrew 的 `pm3` / `proxmark3`，或项目固定的 PM3 Easy 兼容内核；不会探测或执行任意路径。
- 长时间运行的客户端命令在 Tauri 阻塞线程池中执行，并受超时控制。
- 兼容客户端的临时命令脚本以独占方式创建，权限固定为 `0600`，结束后自动删除。

这里没有完整的写前备份、事务提交、整卡回读验证或中断恢复能力。因此，不得通过重新打开 `bundle.active`、改名或隐藏警告来发布这个原型。若未来重启这条产品线，必须先完成独立威胁建模、安全评审和端到端设备测试。

开发验证：

```sh
cd src-tauri
cargo fmt --check
cargo test
cargo check
```
